- 2026-09-27 | Production page-error baseline is 2 errors, not 0 | main 896201c already blocks the Google Fonts stylesheet by CSP on niasave.com in both languages. The PRD expected none. Per the skill's run-day rule the measured baseline wins, so the post-merge check compares against these 2 known errors and fails on any new one. The CSP fix is outside the lane and goes to the team in STATUS.md.
- 2026-09-27 | PRs 64, 66 and 67 are superseded, closed at PR 3 dispatch | all 3 are older than 7 days and only touch Home copy and its guardrail tests, which PR 3 rebuilds from the approved mockup. Diff first and carry anything real into the PR 3 brief.
- 2026-09-27 | Grok runs grok-4.7 on every call, bypassPermissions inside its own worktree | the strongest non-fast model, as the setup block requires; grok-4.7-build-fast is reserved for small fix-ups on an existing PR.
- 2026-09-27 | Home stays inside the lane despite the production splice | vercel-build.sh runs scripts/splice-apple-home.mjs, which overwrites commerce.js's entryHomepage() with lib/commerce/apple-home.snippet.js (401 bytes) at production build time. That snippet only calls homeDashboardMarkup(homeDashboardModel(...)), and all Home copy lives in commerce-home.js and the locales, both in the lane. So PR 1 and PR 3 need no out-of-lane change, on one condition: the names entryHomepage, homeDashboardModel and homeDashboardMarkup and that call shape must not change, or the production build throws. Given to Grok as a hard rule and to PR 0 as a guard.
- 2026-09-27 | Frozen the 553 translation gaps that already exist on main, alongside the 278 copy violations | the PRD asks for a test that fails when a t() line has no translation, but main is already missing 553 of them (hi 225, kn 152, mr 172, bn 2, ta 2). Without a frozen list the test can only be red on day one. The list may shrink, never grow, so any string this build touches must ship in all six languages.
- 2026-09-27 | Baseline sizes live as constants in tests/ui-clarity/limits.mjs | a committed number is editable by definition, so the real protection is the audit: any diff to that file, or growth in BASELINE.json, is an automatic fail unless the numbers shrink. Recorded as a standing supervisor check in GUARDS.md.
- 2026-09-27 | PR 0 sent back rather than merged, though its CI was green | green CI proved the tests pass, not that they can fail. Three of the six guards could not fail: the font-size check compared NaN, Kannada was missing from the banned-word list, and the baseline held staff strings outside the lane. A guard that cannot fail is worse than no guard, because it certifies the build at PR 9.
- 2026-09-27 | The copy guard covers member files only, and staff files stay in the data-lines freeze | commerce-owner.js and commerce-ops.js are staff surfaces that PRD section 4 and DATA-CONNECTIONS section 2 put outside the lane, so their copy can never be cleaned by this build, and PR 9's empty baseline would be unreachable. Their server calls stay frozen, which is the part that matters.
- 2026-09-27 | The baseline ratchet moves into CI against the pull request's base branch | the counts lived in tests/ui-clarity/limits.mjs, inside the builder's own lane, and a count check alone tolerates swapping a cleaned entry for a fresh violation. CI now compares entries against the base branch, so nothing can be added.
- 2026-09-27 | PR 1 also lifts to 14 px any line it rewrites that sits below 14 px today | the font rows are keyed to the exact visible string, and the ratchet rejects any new row, so rewriting a 12 px line like "Checking updates" or "Why Nia" would create a new sub-14 px row and turn CI red. The choice was to relax the ratchet or to bring PR 7's one rule forward for the lines PR 1 touches. Relaxing a guard to fit a schedule is how false greens start, so the type rule comes forward. PR 7 still owns the full three-size pass.
- 2026-09-27 | The watch moved off file-mtime probes and onto the builder's own event stream, the branch head and the run budget | `find -newermt '-40 minutes'` is rejected by this Mac's find as an invalid timestamp, and with stderr suppressed every progress probe reported zero activity, which read as a stalled builder while Grok was in fact on loop 30 with tool calls landing every few seconds. A watch that cannot tell "no progress" from "cannot measure progress" is worse than none, because it triggers the stuck rule against healthy work.
- 2026-09-28 | A8.1 is waived. Kannada and Marathi are not being built | The founder waived A8.1. PR 8 ships the four languages `commerce-i18n.js` supports: English, Hindi, Tamil and Bengali. The `kn` and `mr` files stay on disk and stay current.
- 2026-09-28 | Earn step caption is 16px, not the 17px in picture-card PRD section 4.2 | Section 4.2 says 17px/600 #101828. The clarity rule is three sizes, 14, 16 and 24. The founder picked three sizes. Weight and colour stay 600 and #101828. The number badge stays 16px/700 white on #2C5880. Do not widen the clarity allowlist to fit 17.
